# 运维工具说明（Issue #7）

## 阶段 1

| 工具 | 能力 | 实现 |
|------|------|------|
| Ping | TCP 端口连通与延迟 | 已有 |
| 端口扫描 | 自定义/预设端口列表，有限并发 TCP 探测 | ✅ |
| DNS 查询 | `InternetAddress.lookup`，复制结果 | ✅ |

约束：端口扫描单次最多 64 个端口，超时约 1.5s，**不做**大段爆破式扫描。

## 阶段 2

| 工具 | 能力 | 实现 |
|------|------|------|
| SSH 连接 | `ssh://` URL Scheme 唤起系统客户端 | ✅ |
| 网络诊断 | 本机网卡 + DNS + 80/443 探测汇总 | ✅ |

SSH **不**在 App 内实现协议栈，不存密码。

## 已有

- 远程桌面（外置 / 网关 / WebRTC 骨架）
- 扫码 + Excel 导出

## 后续可选

- 端口扫描历史同步到后端
- traceroute（需平台能力或后端代测）
- 内置简易 SSH（安全与审核成本高，不优先）
